App Version / Update Gate

Control the mobile app's forced and optional update thresholds for each platform.

How this works: Users below the Min supported build are forced to update (the app blocks them until they do). Users between Min supported build and Latest build see an optional update prompt they can dismiss. Users on the latest build see nothing.

Who is on which app version

Accounts seen in the last 30 days. App versions from October 2026 on report their build; older ones cannot, and are counted under "still on an old app". Raise the minimum only once the new version is live for everyone on Google Play and the App Store — a phone below it is stopped at once.
